## 変更1（2026-10-03 JST）— 逆算の合格ライン
- 元の基準（残差 ≤ 0.01点）で方法Aは不合格（合格 646 / 段差 6,597 / 判定不能 37,404組）。
- 原因: 基準が点数の丸めだけを考え、mark の丸め（0.01 単位で公開）を入れていなかった（設計の誤り）。
- 確認（推定値を使わない検証）: positions に正確な枚数があり前後で枚数が変わらない 6,948組で、
  1枚あたりのずれは最大 0.0098（中央値 0.0030）。丸めの理論上の上限 0.01 以内に収まった。
- 新しい基準: |残差| ≤ |枚数|×0.01 + 0.01点。丸めの計算から導いた値で、結果に合わせて調整した値ではない。
- 影響: 1回あたり 0.5点未満の段差（例: 0.1枚の小さな取引の手数料）は見分けられない → その旨を記録する。
- 追加の確認: 自分の鍵の正確な帳簿（公式 fold）で、この基準が誤検出しないかを確かめる。
